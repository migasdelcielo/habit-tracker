# Habit Tracker (Habit Flow) 🎯

Un panel de control web minimalista y moderno para el seguimiento semanal de hábitos, metas diarias y rachas de consistencia.

## 🌐 Demo en vivo

Puedes usar la aplicación directamente desde:
👉 **[https://migasdelcielo.github.io/habit-tracker/](https://migasdelcielo.github.io/habit-tracker/)**

## 🚀 Características

- **Seguimiento Semanal:** Marca tus hábitos día a día de lunes a domingo.
- **Rachas y Estadísticas:** Visualiza tus mejores rachas consecutivas y el porcentaje de efectividad semanal.
- **Gráfico de Consistencia:** Gráfico de barras interactivo con el progreso acumulado por día.
- **Persistencia Local:** Los datos se guardan de forma automática en tu navegador mediante `localStorage`.
- **Sin compilador ni dependencias locales:** Construido con Preact y HTM mediante módulos ES nativos (listo para abrir directamente en el navegador o desplegar en GitHub Pages).

## 🛠️ Tecnologías

- **HTML5 & CSS3:** Variables CSS, grid y flexbox responsivo, tema oscuro.
- **Preact + HTM:** Reactividad ligera y sin `npm install` ni `build steps`.

## 💻 Cómo usarlo

1. Clona el repositorio:
   ```bash
   git clone https://github.com/migasdelcielo/habit-tracker.git
   ```
2. Abre `index.html` directamente en tu navegador favorito.
